# ResumeBuddy 📄
ResumeBuddy is an AI-powered web application that helps students improve their resumes for internships and placements by providing instant, structured feedback.

## Features
- Upload resume (PDF or DOCX)
- Professional feedback mode
- Fun (roast-style) feedback mode
- ATS-focused suggestions
- Student-friendly insights

## Tech Stack
- Frontend: React, TailwindCSS
- Backend: FastAPI (Python)
- AI: Groq LLaMA 3.3 70B
- Resume Parsing: pdfplumber, python-docx
